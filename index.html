Build Android

Hubungkan endpoint backend build Android milikmu.

Backend harus menerima konfigurasi dan file, lalu mengembalikan URL unduhan APK/AAB.
Catatan: file HTML ini adalah antarmuka builder. Kompilasi APK/AAB tetap memerlukan backend Android build. Website satu file di browser tidak dapat mengompilasi dan menandatangani paket Android sendiri.
