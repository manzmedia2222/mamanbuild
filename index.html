Dukungan login aplikasi

Pengaturan kompatibilitas autentikasi untuk website yang akan dijadikan APK.

Login yang ditargetkan: Google, email/password, GitHub, dan provider OAuth lain yang sudah dipasang pada website sumber.
Dipakai sebagai alamat kembali dari browser ke aplikasi. Website/provider OAuth juga harus dikonfigurasi memakai alamat ini agar login eksternal dapat kembali ke APK.
APK akan menyertakan dukungan cookie, navigasi web, dan penanganan tautan aplikasi. Login Google/OAuth tidak bisa dipaksakan hanya dari pembungkus APK: website sumber dan provider harus mengizinkan alur browser/deep link. Jika website memakai Firebase, konfigurasi Firebase dan domain OAuth tetap harus benar.

Yang perlu diketahui

Tentang hasil project dan APK.

  • Browser tidak dapat mengompilasi APK sendiri. File ini menyiapkan project dan workflow cloud build.
  • Workflow membuat APK debug secara otomatis setelah project tersedia di repository GitHub.
  • Email/password dan session website biasanya berjalan di WebView; Google/OAuth memerlukan konfigurasi provider dan deep link yang cocok.
  • APK debug untuk uji coba. Distribusi publik memerlukan signing release key.
